# Shtora Client

Fabric-клиент для Minecraft **1.21.4** в стиле CS2.

- Экран загрузки с буквой **S** из частиц
- Главное меню в стиле CS2 (ник + скин, одиночная / сетевая / настройки / выход)
- Меню клиента на **правый Shift**, оранжевый акцент

## Как собрать .jar через GitHub

1. Создай на GitHub новый **пустой** репозиторий (без README).
2. Залей в него **содержимое** этого проекта — так, чтобы файл `build.gradle`
   лежал в самом корне репозитория (не в подпапке).
3. Открой вкладку **Actions** → workflow **Build Shtora** запустится сам.
4. Дождись зелёной галочки, открой последний запуск.
5. Внизу, в разделе **Artifacts**, скачай **shtora-jar** — внутри готовый
   `shtora-1.0.0.jar`.
6. Положи этот `.jar` в папку `mods` своего лаунчера.

> Артефакт скачивается только с аккаунтом GitHub. Если хочешь прямую ссылку —
> создай тег `v1.0.0` (например, через веб-интерфейс «Releases» → «Create a new
> release» → укажи тег `v1.0.0`). Тогда сборка сама приложит `.jar` к релизу,
> и его можно будет скачать кому угодно без входа.

## Если мод крашит игру

Краш вида `SIGSEGV ... libjvm.so G1SATBMarkQueueSet::filter` — это **баг Java**
в сборке лаунчера, а не мода. Лечится в настройках инстанса → **Java → JVM-аргументы**:

```
-XX:+UseSerialGC
```

И уменьши выделенную память (RAM) до 4–6 ГБ.

## Требования

- Minecraft 1.21.4
- Fabric Loader 0.16+
- Fabric API
- Java 21
